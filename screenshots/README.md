## Capture Instructions

1. Use a clean ServiceNow PDI with demo seed data loaded (see `demo/seed-data-setup.md`)
2. Capture at 1440×900 minimum resolution
3. Crop to remove browser chrome — application content only
4. Save as PNG
5. Place in this directory and update the inventory table above
